# Задача: заменить синтетические тексты в рекламных моках на source-grounded примеры

## Контекст

В коммерческой презентации Яндекс Мед показаны форматы размещения: **Статья**, **Полезное**, **Медиа**, **Событие**, **Performance-продвижение**. В текущих моках часть текстов синтетическая: вымышленные заголовки, источники, бренды, мероприятия и клинические формулировки. Цель — заменить их на реалистичные примеры, построенные поверх реальных медицинских источников, сохранив текущую визуальную механику.

Аудитория первого запуска: терапевты, педиатры, акушеры-гинекологи, неврологи.

## Главный принцип

**Никакой медицинский факт не генерируется из воздуха.**

Для каждого текста сначала выбирается реальный источник, затем через med-pipeline создаются `source → facts → translation → product → audit`. Рекламный текст может упрощать и переупаковывать факт, но не менять population, intervention, comparator, endpoint, цифры, причинность, модальность, ограничения и regulatory status.

Если рекламный формат требует имени партнёра/бренда, а реального партнёрства нет, использовать только явный плейсхолдер `[Партнёр]` / `[бренд партнёра]`. Не создавать ложное впечатление, что реальная компания спонсирует материал.

## Что не устраивает в текущих примерах

1. `Nature Medicine` и другие source labels используются как декоративные элементы, даже когда показанный текст не привязан к конкретной статье.
2. Формулировки вроде «Для практики: сначала сопоставьте пациента...» выглядят как клиническая рекомендация, но не имеют явного evidence span.
3. Несколько карточек повторяют одну и ту же синтетическую фразу про раннюю коррекцию факторов риска.
4. `CardioPharm`, `Medihora`, «Национальный конгресс терапевтов» выглядят как реальные бренды/мероприятия, хотя это вымышленные объекты.
5. В performance-моке смешаны рекламное обещание, медицинский контент и CTA без явной границы между редакционным материалом и партнёрским размещением.

## Требуемые тексты по форматам

### 1. Статья

Нужно сгенерировать:

- `source_label`: реальный источник;
- `publication_date`;
- `content_label`: например `Клинические рекомендации`, `Исследование`, `Регуляторное обновление`;
- `feed_title_ru`: 55–95 знаков, без кликбейта;
- `feed_summary_ru`: 180–320 знаков, 1–2 предложения;
- `practice_note_ru`: 1 короткий абзац или 1–2 буллета; только source-supported applicability/change/limitation;
- `article_title_ru`: развёрнутый заголовок для экрана статьи;
- `brief_ru`: 2–3 предложения для блока «Кратко»;
- `tags`: 2–5;
- `cta`: `Открыть материал` / `Читать источник`.

Не использовать императивы `назначьте`, `отмените`, `переведите пациента`, если источник прямо не является рекомендацией и не поддерживает это действие.

### 2. Полезное

Механика — подборка/чек-лист, собранная из 2–4 реальных источников.

Нужно сгенерировать:

- `collection_title_ru`: 55–95 знаков;
- `collection_deck_ru`: 140–240 знаков, объясняет, что объединяет материалы;
- `why_useful_ru`: одно предложение `Чем будет полезен`;
- 3 карточки, каждая: `source`, `type`, `title_ru`, `summary_ru`;
- `practice_takeaway_ru`: 1 source-grounded вывод для всей подборки;
- `tags`.

Запрещено создавать искусственную «подборку обновлений», если все три карточки основаны на одном и том же тексте.

### 3. Медиа

Нужно сгенерировать:

- `author_or_source`;
- `media_type`: видео / подкаст / разбор;
- `media_title_ru`: 50–90 знаков;
- `media_teaser_ru`: 160–280 знаков;
- `what_inside_ru`: 2–3 коротких пункта;
- `duration`: только если она есть у источника;
- `specialty`;
- `cta`: `Смотреть` / `Слушать` / `Открыть разбор`.

Если используется реальное видео/подкаст, не приписывать ему спонсора или эксперта, которого нет в источнике.

### 4. Событие

Нужно сгенерировать только из реального upcoming event:

- `event_name_ru` — официальный или аккуратно переведённый;
- `organizer`;
- `date`;
- `place_or_online`;
- `event_summary_ru`: 140–240 знаков;
- `audience`;
- `credit_badge`: CME/НМО только если официально подтверждено;
- `price_badge`: только если подтверждено;
- `cta`: `Зарегистрироваться`.

Не придумывать даты, НМО, стоимость или организатора.

### 5. Performance-продвижение

Это **не отдельный медицинский источник**, а рекламная упаковка одного из source-grounded материалов выше.

Нужно сгенерировать:

- `search_query_ru`: естественный профессиональный запрос врача;
- `ad_label`: `Реклама`;
- `partner_label`: `[Партнёр]`, если реальный партнёр не задан;
- `ad_title_ru`: 45–75 знаков;
- `ad_description_ru`: 100–180 знаков;
- 2–3 sitelinks: например `Кратко`, `Алгоритм`, `Все материалы`;
- `cta`;
- `landing_material_id`: ссылка на конкретный source-grounded материал из этого же run.

Нельзя писать efficacy/safety claims, которых нет в выбранном источнике. Нельзя превращать editorial summary в рекламное обещание.

## Кандидаты источников для первой итерации

### A. Акушеры-гинекологи — лучший кандидат для «Статья»

**ACOG, 16.04.2026 — Updated Guidance on Evaluation of Postmenopausal Bleeding**  
URL: https://www.acog.org/news/news-releases/2026/04/acog-publishes-updated-guidance-evaluation-postmenopausal-bleeding

Почему подходит:
- есть чёткое изменение практического guidance;
- можно достоверно показать `Кратко` и `Для практики`;
- понятная профессиональная аудитория;
- source label и дата реальные;
- хорошая замена синтетическому примеру «когда пересматривать риск».

Ожидаемый смысл заголовка, не финальный текст:  
`Постменопаузальное кровотечение: ACOG обновил первичную диагностику`

### B. Педиатры — лучший кандидат для «Полезное»

**AAP / Pediatrics, 22.06.2026 — Prevention, Screening, Diagnosis, and Treatment of Iron Deficiency and Iron Deficiency Anemia in Infants, Children, and Adolescents**  
URL: https://publications.aap.org/pediatrics/article/158/1/e2026077414/207901/Prevention-Screening-Diagnosis-and-Treatment-of

Почему подходит:
- много конкретных actionable items;
- легко разложить на чек-лист/шпаргалку;
- есть возрастные окна, screening, профилактика и лечение;
- хороший тест на сохранение доз, возраста и единиц.

Ожидаемый смысл заголовка:  
`Дефицит железа у детей: новые ориентиры AAP по скринингу и профилактике`

### C. Терапевты — кандидат для «Медиа»

**NEJM, 20.05.2026 — Cardiovascular Risk Factors — Hypertension**  
URL: https://www.nejm.org/doi/abs/10.1056/NEJMp2516850

Почему подходит:
- это реальный видеоформат;
- тема широкая для терапевтов;
- источник сам описывает practical strategies для контроля АД;
- позволяет заменить синтетическое «Иван Петров / Название поста» на реальный media item.

Ожидаемый смысл заголовка:  
`Артериальная гипертензия: практические стратегии контроля давления`

### D. Неврологи — кандидат для research/article card

**JAMA, 10.09.2026 — Loberamisal for Acute Ischemic Stroke: The LAIS Randomized Clinical Trial**  
URL: https://jamanetwork.com/journals/jama/fullarticle/2854043

Почему подходит:
- полноценное РКИ;
- можно проверить extraction PICO, sample size, endpoints и ограничения;
- хорошо тестирует различие `что нашли` vs `что делать врачу`.

Альтернатива для regulatory-news формата:  
**FDA, 03.09.2026 — FDA Approves First Drug to Treat Alexander Disease**  
https://www.fda.gov/news-events/press-announcements/fda-approves-first-drug-treat-alexander-disease

### E. Терапевты / эндокринология — кандидат для «Полезное» или performance landing

**ADA — Standards of Care in Diabetes—2026, Abridged for Primary Care Professionals**  
URL: https://diabetesjournals.org/docm-care/article/doi/10.2337/doc26-aint/164620/Standards-of-Care-in-Diabetes-2026-Abridged-for

Дополнительный source для конкретных изменений:  
https://diabetesjournals.org/care/article/49/Supplement_1/S6/163930/Summary-of-Revisions-Standards-of-Care-in-Diabetes

Почему подходит:
- предназначено именно для primary care;
- много конкретных revision points;
- хорошо работает как `4 изменения, которые стоит проверить` без выдуманных карточек.

### F. Событие — реальная замена синтетическому «Национальному конгрессу терапевтов»

**2026 AAP National Conference & Exhibition**  
2–6 October 2026, San Diego Convention Center  
URL: https://www.aap.org/2026-National-Conference-Exhibition-ALL-ACCESS-in-person-virtual

Подтверждённые данные, которые можно использовать: 350+ educational sessions, 70+ topic areas, up to 97 CME credits, in-person + virtual access. Не добавлять другие цифры без проверки.

## Пример направления для performance-мока

Выбрать ACOG source выше как landing content.

Не финальный copy, а направление:

- query: `постменопаузальное кровотечение алгоритм диагностики`
- ad title: `Что изменилось в оценке постменопаузального кровотечения`
- description: `Краткий разбор обновления ACOG 2026: первичная оценка, место ТВУЗИ и биопсии, ограничения.`
- sitelinks: `Кратко` · `Для практики` · `Открыть источник`
- partner: `[Партнёр]`

Перед использованием copy должен пройти Fact Extractor + Medical Auditor.

## Что Codex должен сделать

1. Прочитать существующий run FDA, если он доступен локально, но не использовать его как gold автоматически.
2. Прогнать минимум 4 источника из списка A–E через текущий med-pipeline.
3. Для каждого создать source-grounded варианты текстов для всех применимых рекламных форматов.
4. Для `Полезное` собрать минимум одну подборку из нескольких независимых source IDs.
5. Для `Performance` использовать только уже прошедший audit landing material.
6. Составить `AD_COPY_MATRIX.md` со столбцами:
   - format
   - audience/specialty
   - source
   - original title
   - source-grounded Russian copy
   - evidence refs
   - CTA
   - partner placeholder
   - audit decision
   - human review notes
7. Составить `MOCK_REPLACEMENTS.md` в формате `текущий синтетический текст → рекомендуемый replacement` для каждого видимого элемента моков.
8. Ничего не записывать в `evals/gold/` без explicit human approval.

## Acceptance criteria

- 0 fabricated journals, organizations, brands, dates, event details, drug facts or numeric claims;
- 100% медицинских claims имеют evidence ref;
- все числа/дозы/возрастные пороги проходят deterministic checks;
- `Для практики` не сильнее источника;
- рекламная маркировка визуально/семантически отделена от editorial source attribution;
- текст звучит как профессиональная лента для врача, а не как consumer health / pharma brochure;
- минимум по одному реалистичному примеру для терапевта, педиатра, акушера-гинеколога и невролога.
